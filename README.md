# Customer Behaviour Analysis

## 📌 Project Overview

This project analyzes **customer purchasing behaviour** using SQL, Python, and Power BI. It helps identify customer trends, preferences, spending patterns, and purchasing behaviour.

## 🛠️ Technologies Used

* **SQL / PostgreSQL** – Data querying and analysis
* **Python** – Data cleaning and analysis
* **Pandas & NumPy** – Data processing
* **Power BI** – Interactive dashboards and visualization

## 🔄 Workflow

1. Store and manage customer data using PostgreSQL.
2. Use SQL queries to analyze customer behaviour.
3. Clean and process the data using Python.
4. Perform exploratory data analysis using Pandas.
5. Create an interactive Power BI dashboard.
6. Visualize customer trends, purchases, and key performance metrics.
7. Generate meaningful business insights.

## 📊 Key Analysis

* Customer purchasing patterns
* Product preferences
* Sales and spending behaviour
* Discount usage
* Customer demographics
* Purchase trends

## 🎯 Objective

To understand customer behaviour and transform raw customer data into **meaningful business insights** using SQL, Python, and Power BI.
